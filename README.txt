GAMEMIND — веб-приложение для учёта игрового времени.

Публикация на GitHub Pages:
1. Загрузите index.html в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Branch: main, folder: / (root), затем Save.

Данные приложения хранятся локально в браузере пользователя.
